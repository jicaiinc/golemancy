> 最后更新：2026-03-13

## 一、定位

**超级个体 = 一个人的公司**。Golemancy 为超级个体提供一整套 AI 角色团队，替代传统企业中需要雇佣的各个职能岗位。

**产品策略**：免费层获客（通用角色） → 付费层变现（专业角色）。Memory 建粘性，Team 做深度。

### 5.2 免费 vs 付费的技术差异

| 维度 | 免费层 | 付费层 |
|------|--------|--------|
| Agent 数量 | 单 Agent | 多 Agent Team |
| Memory | 基础 Memory | 深度 Memory + 跨 Agent 共享 |
| MCP | 基础 MCP（搜索、浏览器） | 专业 MCP（CRM、会计、SEO 工具） |
| Skills | 通用 Skills | 专业领域 Skills |
| Cron | 基础定时（日报） | 复杂定时（多任务编排） |
| Built-in Tools | Browser + Memory | Browser + Bash + Memory |

### 5.3 Memory 策略

每个项目的 Agent 通过 Memory 实现「越用越懂你」：

| Memory 类型 | 内容 | 目的 |
|-------------|------|------|
| **用户偏好** | 写作风格、术语偏好、语气倾向 | 个性化输出 |
| **业务上下文** | 公司信息、产品详情、竞品清单 | 减少重复输入 |
| **历史记录** | 之前的调研结果、分析结论 | 增量更新而非从零开始 |
| **反馈学习** | 用户修正过的输出 | 持续改进质量 |
