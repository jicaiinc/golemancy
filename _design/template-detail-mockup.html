Template Detail Panel Redesign

Three design approaches for showing agent details. Click tabs to switch.

A: Agent Cards
B: Compact List
C: Inventory Grid
Option A: Agent Cards
Each agent in a card with colored pills for skills (purple), MCP (cyan), and tools (amber).
Clean visual hierarchy. Works well for 2-4 agents.

Very space-efficient. Good for templates with many agents. Closer to current design.
