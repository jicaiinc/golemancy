# 超级个体 AI Agent 项目体系 — 需求文档

> 创建日期：2026-03-13
> 状态：需求定义

## 背景

Golemancy 产品已开发完成，需要面向真实用户需求构建 showcase 场景。目标用户群体：**超级个体**（创业者、小微企业主、自由职业者、追赶 AI 时代的个人）。

## 核心理念

- **角色替代，而非任务自动化** — 替代职场/生活中的真人角色
- **一个人的公司** — 超级个体 = 工作与生活没有强分界线的全能选手
- **Project = 能力域** — 每个能力对用户来说是一个独立项目（翻译是一个项目，营销是一个项目）

## 产品策略

| | 免费层 | 付费层 |
|--|--------|--------|
| 定位 | 获客，通用角色，人人需要 | 变现，专业角色，替代雇人 |
| 形态 | 单 Agent + Skill | Agent Team 多角色协作 |
| 粘性 | Memory 越用越懂你 | 深度专业 + 不可替代性 |

## 要求

### 1. Project 级别组织
每个能力域作为一个 Project，包含：
- 项目名称与定位
- 包含的 Agent 列表
- 每个 Agent 配备的 Skills
- 每个 Agent 配备的 MCP Server
- Built-in Tools 配置（bash, browser, memory 等）
- Cron Job 场景（如有）

### 2. 复用已有实现
- 优先复用 GitHub 上已有的成熟 Agent、Skills、MCP 实现
- 参考 `trending_archive/_docs/agent-mcp-skills-analysis/README.md` 中的调研结果
- 科研、学术等非主流市场但实现成熟的也纳入

### 3. 覆盖范围
必须包含的维度：
- 市场调研 / 信息搜集
- 品牌 / 营销 / 内容创作与分发
- 销售 / 客户沟通
- 客服 / 售后
- 财务 / 税务
- 法务 / 合同
- 产品 / 项目管理
- 行政 / 秘书
- 学习 / 成长
- 翻译 / 跨语言
- 数据分析
- 生活规划
- 其他通过调研发现的有价值能力域

### 4. 行业交叉分析
- 考虑不同行业（电商、自媒体、独立开发者、咨询、设计、自由职业）
- 找出通用交集能力
- 标注行业特有能力

### 5. 输出格式
- Markdown 文档
- 包含总览表格 + 每个 Project 的详细配置
- 标注哪些是已有实现可直接复用，哪些需要自建
- 尽量全面、丰富
