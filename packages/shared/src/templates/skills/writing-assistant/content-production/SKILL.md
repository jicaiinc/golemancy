# Content Production

Full execution framework for producing finished, publishable content from concept to completion.

## Three Operating Modes

**Mode 1: Research & Brief**
- Competitive content analysis (top 5-10 ranking pieces)
- Search intent mapping
- Source gathering (3-5 credible references minimum)
- Structured content brief production

**Mode 2: Draft**
- Outline-first approach with 4-7 H2 sections
- Hook-focused introductions (3-4 sentences maximum)
- Section-by-section: point first, proof second
- Actionable conclusions without padding

**Mode 3: Optimize & Polish**
- SEO optimization pass (title tags, keywords, alt text)
- Readability audit (score 70+ minimum)
- Structure validation and internal linking
- Pre-publish quality gates

## Initial Context Requirements

Gather before writing:
- Specific topic or working title
- Primary search keyword (if SEO-relevant)
- Reader profile and existing knowledge level
- Content objective (inform, convert, build authority, trial)
- Target word count range
- Related existing content inventory

## Search Intent Mapping

| SERP Pattern | User Intent | Approach |
|---|---|---|
| "What is / How to" dominates | Informational | Comprehensive guide |
| Product pages, reviews | Commercial | Comparison or buyer's guide |
| News, updates dominant | Navigational/news | Original angle only |
| Forum results (Reddit, Quora) | Discovery | Opinionated with substantiation |

## Drafting Principles

**Intro formula:**
1. Name the reader's problem or situation
2. State what this piece provides
3. Optional: establish credibility

**Section structure per H2:**
- Lead with main point (first sentence)
- Prove with example, statistic, or comparison
- Include one actionable takeaway

**Conclusion:**
- Core argument summary (1-2 sentences)
- Single most important next action
- Goal-aligned CTA

## SEO Optimization Checklist

- Title tag: primary keyword, under 60 characters, curiosity-driven
- H1: differs from title tag, keyword-rich, natural
- H2 sections: 2-3 contain secondary keywords
- First paragraph: primary keyword within first 100 words
- Image alt text: descriptive, keyword-inclusive
- URL slug: short, keyword-forward
- Meta description: 150-160 characters with keyword and action hook

## Pre-Publish Quality Gates

- Primary keyword appears 3-5 times naturally
- Every factual claim has source attribution
- Minimum one visual element
- Intro avoids cliched openings
- Readability score >= 70
- Word count within 10% of target

## Proactive Risk Flags

- **Thin content**: High-authority competitors with 2,000+ word pieces
- **Cannibalization**: Existing content already ranking for target keyword
- **Intent mismatch**: Awareness positioning on transactional keywords
- **Citation gaps**: Claims without specific sources
- **CTA disconnects**: Goals without visible call-to-action
